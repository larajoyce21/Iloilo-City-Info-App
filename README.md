# Iloilo City Info App 

**A Mobile Application to Promote Iloilo City**

---
## Project Description

The **Iloilo City Info App** is a mobile-based information system designed to promote tourism, support local businesses, and 
provide essential city information in one centralized platform.

This application allows users to explore Iloilo City’s tourist attractions, accommodations, restaurants, government services, and emergency contacts with ease.

It also includes an **admin panel** that enables administrators to manage content dynamically, ensuring that information is always updated and relevant.

---

## Objectives

* Promote Iloilo City as a top tourist destination
* Provide accessible and organized city information
* Support local businesses through digital visibility
* Improve user experience through a centralized platform
* Enable administrators to manage content efficiently

---

##  Key Features

### User Features

* Search functionality for places, services, and establishments
* Browse tourist spots and cultural sites
* View hotels and accommodations with details and images
* Discover restaurants and cafés
* Access government offices and services
* View emergency contacts
* Google Maps integration for directions
* Mobile-friendly and responsive design

---

### Admin Features

* Dashboard with analytics and statistics
* Manage categories (CRUD functionality)
* Manage businesses and establishments
* Manage hotel listings with image uploads
* Manage government offices and services
* Approve or reject business submissions
* Monitor user engagement and activity
* Real-time updates reflected on user pages

---

## System Modules

* **Tourism Module** – Tourist spots, cultural sites, landmarks
* **Business Directory Module** – Restaurants, cafés, shops
* **Accommodation Module** – Hotels and lodging services
* **Government Services Module** – Offices and procedures
* **Emergency Module** – Important hotlines and contacts
* **Admin Management Module** – Full content control system

## Database Design

The system uses a relational database with the following main tables:

* `users` – Admin and user accounts
* `categories` – Different app categories
* `businesses` – Registered establishments
* `hotels` – Hotel listings with images
* `tourist_spots` – Tourist destinations
* `emergency_contacts` – Emergency numbers
* `submissions` – Business submissions for approval

## Installation Guide

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/iloilo-city-info-app.git
```

### 2. Move Project Folder

Copy the folder into:
```
C:\xampp\htdocs\
```

### 3. Start Server
* Open XAMPP
* Start **Apache** and **MySQL**

### 4. Setup Database
* Open **phpMyAdmin**
* Create a database (`app`)
* Import the provided `app-2026` file

### 5. Run the Application
Open your browser and go to:
```
http://localhost/BLOCK-APP/index.php
```
